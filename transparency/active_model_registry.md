# Active Model Registry

## Scope

This audit covers the active operating-override workflow run by `source(file.path("R", "run_active_workflow.R"))`. The workflow sources scripts `R/10` through `R/14` in order (`R/run_active_workflow.R:1-5`). The registry is organized to avoid repeating shared specification details in every model row. Variable construction and raw-data lineage are documented separately in `transparency/active_variable_dictionary.md`.

The requested `outputs/report/main_results/main_results_10_14.md` was not present when this audit was written.

## Status Values

| status | meaning |
| --- | --- |
| `headline` | Main result model or preferred repeated-event DiD specification. |
| `robustness` | Alternative specification included for sensitivity checks. |
| `needs review` | Specification is explicit in code but has an audit issue or interpretive point needing human review. |
| `supporting` | Supporting/descriptive artifact, not a fitted model. No fitted model rows currently use this status. |
